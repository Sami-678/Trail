                     * Git add or push
These are the process of adding the code in github using git
1) First  create a repository in github and then make a new folder in filemananger 
2) write this command in terminal "git remote add origin and the link of "that repo inside the code button
3) then type "git branch -M main" 
4) then check the status of that folder  , i.e which files are not in stage
5) then type " git status ",
6) then type "git add ./readme.md" or any other file which you want to take in stage
